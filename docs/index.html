After loading your data, define the genome scope, the gene categories, and the starting gene used to organize the final genome order.

Because each choice depends on the previous one, Step 2 is grouped in a single panel with three connected columns.

2.1.1 Genome type

Select whether the current run should analyze mitochondrial or chloroplast genomes. This choice controls the available gene catalog in the next column.

2.1.2 Gene categories

Choose which gene groups should be extracted for the analysis. You can combine CDS, rRNAs, and tRNAs according to the biological question you want to test.

2.1.3 Starting gene

Pick the gene that should be treated as the starting point for the genome order.

FASTA Sequence Header Format

Choose how you want to format the sequence header for your FASTA file:

Simple Format (Recommended)

Header: >accession species_name

Example: >NC_001943 Homo sapiens

Extended Format

Header: >accession | species_name | gene_name | additional_info

Example: >NC_001943 | Homo sapiens | COI | mitochondrial

Minimal Format

Header: >accession

Example: >NC_001943

After running your analysis, export your results in various formats for further analysis or publication-ready figures.

3.1 Fasta File

Select a gene to export its sequences in FASTA format. You can choose how to format the sequence header.

3.2 Input File for External Tools

Create input files for analysis tools like CREx, CREx2, TreeREx, or qMGR.

3.3 Puzzle-like Plot

Generate publication-ready figures showing gene order patterns with or without user modifications.

3.4 Individual Gene Plot

Create a detailed visualization of a single gene's pattern across all genomes.

4.1 Filter by Patterns

Display only genome patterns instead of all sequences to highlight shared gene organizations.

4.2 Publication-Ready Figure

Export genome patterns as high-quality figures suitable for publication.

4.3 Patterns Data File

Export pattern data in text format for further analysis or documentation.

4.4 Save Analysis

Download your complete analysis as a PUMAS file to share or import later.
